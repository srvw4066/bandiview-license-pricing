## 几个容易被忽略的限制

**一个密钥对应的是台数，不是一个账号随处登录。** 官方明确写了使用额外设备需要 2PC 授权。换新电脑、重装系统、旧机器还没淘汰，这些场景都要先想清楚这台算不算第二台。

**密钥是邮件发的，不是站内账户里躺着。** 付款完成后，授权信息连同产品密钥会发到你填的邮箱。购买时用的邮箱要能长期收信，别用临时邮箱。真丢了也能自救，用购买时注册的邮箱提交一下，授权信息会重新发过来。

**升级折扣只覆盖 1PC 到 2PC。** 想装第三台，还是得再加授权，别指望靠升级一路加下去。

**专业版和免费版的差别就是广告和专属功能。** 这两样对你不痛不痒的话，先别急着付钱，用免费版跑一段时间再决定。

**授权属于虚拟商品，退款通常有条件。** 需要发票或者对退款规则有要求的，下单前先跟客服确认清楚，别等付完款再问。
